# eaa_website

A small static website introducing effective altruism.

## Pages

- `index.html` — home page with a one-line description of effective altruism
- `about.html` — a short overview of the core ideas and common focus areas
- `styles.css` — shared styling (responsive, with light and dark support)

## Running locally

No build step is needed. Open `index.html` directly in a browser, or serve the
directory:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.
